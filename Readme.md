# ☁️ CloudNine

CloudNine is a modern weather application built with React Native. 
It provides real-time weather information, forecasts, air conditions, 
and weather details for different cities using the OpenWeather API.

## 🚀 Features

- 🌤️ Real-time weather information
- 🔍 Search weather by city
- 📅 Weather forecast
- 💨 Air conditions
- 🌡️ Temperature and feels-like temperature
- 💧 Humidity information
- 💨 Wind speed
- 🌍 Weather information for different cities
- 📱 Mobile-first React Native interface

## 🛠️ Technologies

- React Native
- Expo
- JavaScript
- OpenWeather API
- React Native StyleSheet

## 🎯 Purpose

CloudNine is being developed as a learning project to practice 
React Native, API integration, mobile UI development, and 
component-based application architecture.
